# Sistem Voting

Fitur ini digunakan mahasiswa untuk memberikan suara kepada kandidat Direktur Utama HMTI.

## Cara Voting
1. Mahasiswa login menggunakan NIM.
2. Mahasiswa membuka halaman kandidat.
3. Mahasiswa memilih kandidat.
4. Sistem menyimpan suara ke database.
5. Hasil suara diperbarui secara otomatis.
