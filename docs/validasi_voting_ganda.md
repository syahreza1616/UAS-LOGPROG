# Validasi Voting Ganda

Sistem E-Voting menerapkan validasi agar setiap mahasiswa hanya dapat memberikan satu suara.

## Validasi
1. Sistem memeriksa status voting mahasiswa.
2. Jika mahasiswa sudah memilih, sistem menolak voting berikutnya.
3. Jika belum memilih, suara dapat disimpan.
4. Status mahasiswa diperbarui setelah berhasil voting.
