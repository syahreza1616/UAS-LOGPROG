# Penutupan Pemilu

Fitur penutupan pemilu digunakan admin untuk mengakhiri proses pemungutan suara.

## Fungsi
1. Admin dapat menutup pemilu melalui dashboard.
2. Sistem mengubah status pemilu menjadi tidak aktif.
3. Mahasiswa tidak dapat melakukan voting setelah pemilu ditutup.
4. Hasil pemilihan dapat ditampilkan melalui halaman pengumuman pemenang.
