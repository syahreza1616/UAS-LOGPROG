# Dashboard Hasil Voting

Dashboard hasil voting digunakan untuk menampilkan perolehan suara setiap kandidat.

## Informasi yang Ditampilkan
1. Nama kandidat.
2. Total suara setiap kandidat.
3. Perbandingan jumlah suara.
4. Grafik hasil voting.

Admin dapat memantau hasil pemilihan melalui halaman dashboard hasil voting.
