# E-Voting HMTI

Website E-Voting Pemilihan Direktur Utama HMTI FT UNSIKA Periode 2027.

## Teknologi
- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript

## Fitur
- Login mahasiswa
- Login admin
- Manajemen kandidat
- Pemungutan suara
- Validasi satu mahasiswa satu suara
- Hasil voting
- Statistik pemilih
- Penutupan pemilu

## Cara Menjalankan
1. Install library dari requirements.txt.
2. Jalankan aplikasi menggunakan Python.
